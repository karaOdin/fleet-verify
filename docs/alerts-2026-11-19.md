## Why off_route counts only time spent driving

With the literal rule (10 min continuously >150 m from the route) the day raises 106 off_route alerts: line 04: 35, line 05: 25, line 10: 14, line 11: 4, line 12: 9, line 16: 13, line 17: 3, line 18: 3.
Lines 04 and 05 raise one on every bus, every round, 11–30 min. Those buses stand still (median 0 km/h) at one spot
~600 m from the route near their shared terminal (35.6965, 4.567) between trips; the batch already calls these
periods `excursion` (waiting off the line). Lines 10 and 16 have smaller layover spots of the same kind.
That is a layover place, not a detour, and the route does not need redrawing for it. The rule now opens an
off-route episode on distance but counts only driving time (≥ `idle_kmh`) towards `off_route_min`.

No line-05 detour shows on this day: with the driving-time rule line 05 raises no alert. If the road works
start later, every bus of the line will show the same off_route stretch at the same place: that is the sign
the route needs redrawing, not that drivers misbehave.
